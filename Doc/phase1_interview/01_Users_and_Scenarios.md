## 주요 시나리오

### 시나리오 1: 아침 시작 (P-01)

```
시작 조건: 사용자가 아침 첫 MC 진입
흐름:
1. iet03가 MC 실행
2. MC가 "오늘의 흐름" 화면을 자동 표시 (US-FLOW-01)
3. 화면 상단에 오늘 프리뷰 — 일정, 이월 태스크, 어제 마지막 메모 (US-DAY-01)
4. iet03가 빠른 메모/태스크를 Quick Capture로 입력 시작
완료 조건: 첫 입력 또는 첫 화면 조회 완료 (사용자 결정)
```

### 시나리오 2: 일과 중 컨텍스트 진입 (P-01)

```
시작 조건: 일과 중 알림/스케줄이 도래하거나 작업 전환 시점
흐름:
1. iet03가 흐름/캘린더에서 다가오는 일정/태스크 클릭
2. MC가 우측 컨텍스트 패널 펼침: 연결된 태그·프로젝트, 관련 .md 메모, Git 이슈 (US-FLOW-03, US-GIT-01)
3. iet03가 메모/태스크 추가 또는 기존 항목 편집
4. 변경 즉시 흐름·캘린더에 반영
완료 조건: 다음 컨텍스트로 이동
```

### 시나리오 3: 저녁 회고 (P-01)

```
시작 조건: 일과 종료 시점, iet03가 회고 화면 진입
흐름:
1. MC가 오늘 항목 목록을 표시 (완료/미완료/지연 상태별)
2. iet03가 미완료 항목에 짧은 반성 메모를 단다 (US-DAY-03)
3. 미완료 태스크를 내일로 이월하거나 보류 처리
4. MC가 회고 메모를 오늘 .md 파일에 추가 (단일 원본 유지)
완료 조건: 회고 완료 표시
```
