## 사용 시나리오 (대표 3가지)

### 시나리오 A — 아침 루틴

```
1. MC 첫 실행 → 아침 프리뷰 화면
2. 오늘 일정 + 이월 태스크 한눈에 파악
3. Quick Capture 또는 음성 캡처로 떠오른 항목 추가
4. 오늘의 집중 프로젝트 클릭 → 컨텍스트 패널에서 관련 메모·이슈 확인
```

### 시나리오 B — 일과 중 컨텍스트 복원

```
1. 특정 태스크 클릭
2. 컨텍스트 패널 펼침 → 연결된 .md 메모 + GitHub 이슈 + 진척도 동시 확인
3. GitHub 이슈 새로 생성 → MC에서 직접 연결
4. 이동 중 Telegram으로 새 아이디어 캡처 → MC에 자동 수신
```

### 시나리오 C — 저녁 회고

```
1. 저녁 회고 화면 진입
2. 오늘 완료/미완료 항목 리스트 확인
3. 미완료 항목 → 이월 또는 보류 선택
4. 반성 메모 입력 → MC-Notes/YYYY/MM/DD-review.md 저장
```
